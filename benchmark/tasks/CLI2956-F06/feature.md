# Dynamic option defaults

An option default is dynamic when it is a non-empty dictionary whose keys are full long option names beginning `--` and whose values are dictionaries from stringified dependency values to target defaults. All other dictionaries remain ordinary static defaults for custom parameter types. After all explicit values, environment variables, default-map values, and ordinary defaults are parsed, resolve dynamic defaults whose target source is still `DEFAULT`. Later dependency entries override earlier matching entries; no match selects `None`.

Resolve referenced dynamic options first, independent of decorator order. Reject an unknown long option with `UsageError`, a dependency cycle with `UsageError`, and a recognized dynamic mapping whose value is not a dictionary with `TypeError`. The selected raw default, including `None`, passes exactly once through the target option's normal type, required, and callback pipeline. An explicit target value from command line, prompt, environment, or default-map always wins. Boolean dependency values match `"True"` and `"False"`. With `show_default=True`, help displays `[default: (dynamic)]`. No second-pass helper or private representation is prescribed.
