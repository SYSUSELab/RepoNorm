# Norm4Code

The task environment provides a read-only repository knowledge directory.
Read its `START.md` once before using a rule for navigation and any collection
limitations. Use `catalog.md`, `by-path/`, or linked rule details as useful for
the task. You may search these files directly; there is no required reading
order after `START.md`.

Apply each rule within its stated scope and when its conditions hold, respecting
exceptions. `required`, `recommended`, and `observed` have different strength:
an observed convention describes existing practice and does not by itself
prohibit a change requested by the task. `reference_only` is context, not a
default action. An explicitly unconfirmed rule remains uncertain.

Open linked details when evidence, ambiguity, or a conflict matters. Evidence
locations identify sources, not the rule's scope. A command mentioned in a rule
does not by itself authorize repository-wide changes or external side effects.

Use relevant knowledge alongside the task requirements and repository code.
Keep edits focused on the task; leave unrelated conventions alone.
